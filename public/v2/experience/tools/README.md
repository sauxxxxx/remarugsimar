# Career tool logos

Vue.js, Node.js, Flutter, Supabase, Firebase, WordPress, JavaScript, and Tailwind CSS SVGs are from [Devicon](https://github.com/devicons/devicon). The original MIT license is included in DEVICON-LICENSE.txt.

The Elementor SVG is from [Simple Icons](https://github.com/simple-icons/simple-icons). The source license is included in SIMPLE-ICONS-LICENSE.txt.

Monochrome SVGs are displayed in white by CSS for contrast on the dark background. Logos retain their original shapes; names identify the technologies used in each role.
